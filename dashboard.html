About

What this platform does and how it is built.

Bird Population Decline AI demonstrates how satellite remote sensing can support habitat monitoring. For a given location it:

  • Fetches Sentinel-2 multispectral imagery via Sentinel Hub
  • Computes NDVI / NDWI / NDBI from the spectral bands
  • Derives land-cover from index thresholds
  • Scores habitat health and bird-decline risk from NDVI
  • Charts NDVI time-series to reveal gradual habitat change
  • Generates a PDF report for documentation

For the full pipeline see the Methodology page, or read the project background on the About page.

Technology Stack

Remote Sensing: Sentinel-2 MSI via Sentinel Hub API
Processing: Python serverless (NumPy, tifffile, Matplotlib)
Frontend: Mapbox GL JS + Chart.js on a static site
Hosting: Vercel (static + serverless functions)

Index Formulas

NDVI = (NIR − Red) / (NIR + Red) — vegetation health
NDWI = (Green − NIR) / (Green + NIR) — water content
NDBI = (SWIR − NIR) / (SWIR + NIR) — built-up areas
Habitat = (NDVI + 1) × 50 · Risk = 100 − Habitat
